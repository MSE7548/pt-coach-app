# PT Coach OS PWA v1

빌드 도구가 없다. 정적 파일 그대로 올리면 돌아간다.

## 왜 이 순서로 만들었나

[PWA 요구사항](../docs/superpowers/specs/2026-08-10-pwa-recording-requirements.md)이 정한 대로, **iOS 실측 결과에 영향받지 않는 부분을 먼저** 만들었다.

| 기능 | v1 | iOS 결과에 걸렸는가 |
|---|---|---|
| 회원 선택 | **켬** | 아니오 |
| 회차·시간 자동 채움 | **켬** | 아니오 |
| 파일명 생성·복사 | **켬** | 아니오 |
| 녹음·조각 저장·복구 | **끔** | **예 — 실측 실패** |
| 종료 안전망 | 끔 | 녹음에 딸림 |
| 업로드 | 없음 | 아니오 |
| 푸시 알림 | 로컬 알림만 | 아니오 |

**녹음은 `app.js`의 `RECORDING_ENABLED = false`로 꺼져 있다.** 코드는 지우지 않았다 — 네이티브 래퍼로 감싸면 그대로 켠다. 2026-08-11 실기기 측정에서 화면을 끈 62분 녹음이 **652바이트**로 끝났고, 화면을 켜둔 2차도 백그라운드 전환만으로 끊겼다.

오늘 실제로 돈을 태운 건 녹음이 아니라 파일명이었다. 284건 중 5건이 `제험 홍길동님 6,23.m4a`처럼 이름 앞에 단어가 붙거나 표기가 달라 회원 추출에 실패했다. **회원 선택 하나가 그 셋을 원천 차단한다.**

## 실행

```
python -m http.server 8787 --bind 127.0.0.1
```

`http://127.0.0.1:8787`을 연다. 마이크는 `localhost`나 `https://`에서만 열린다. **파일을 직접 열면(`file://`) 녹음이 안 된다.**

## 회원 목록

**실명은 저장소에 두지 않는다.** `app/members.json`은 gitignore 대상이다.

```json
[
  { "id": "notion-page-id", "name": "회원이름" }
]
```

없으면 `members.sample.json`(가짜 3명)으로 떨어진다. 나중에 Notion 회원 코어 DB와 동기화한다.

## 파일명 규칙 — 건드리지 말 것

Stage 1은 파일명에서 `^(.+?)님`으로 회원을 뽑는다. 그래서 파일명은 **반드시 회원 이름으로 시작**한다.

```
홍길동님 6,11.m4a
```

`tests/test_pwa_filename_contract.py`가 이 규약을 지킨다. `app.js`의 템플릿이 바뀌면 테스트가 깨진다.

녹음 파일 확장자는 브라우저가 주는 형식을 따른다(iOS Safari는 `m4a`, 그 외는 대개 `webm`). **`webm`을 Stage 1이 받는지는 아직 확인하지 않았다.**

## 종료 안전망

종료 누락은 실수가 아니라 개인정보 사고다. 다음 수업까지 이어지면 동의하지 않은 회원의 발화가 들어간다.

| 순서 | 장치 | 시점 |
|---|---|---|
| 1 | 다음 회원 선택 시 이전 녹음 자동 종료 | 다음 수업 시작 |
| 2 | 무음 5분 알림, 10분 자동 종료 | 대화 중단 |
| 3 | 55분 / 70분 알림 | 시간 |
| 4 | 90분 자동 종료 | 최후 |

90분으로 끊긴 파일은 `(부분)`을 붙여 내려받는다. 다른 회원 발화가 섞였을 수 있으므로 그대로 파이프라인에 넣지 않는다.

무음 감지는 음성 인식이 아니라 **소리 크기만** 읽는다(`AnalyserNode`). 배터리 부담이 작다.

## 조각과 복구

5분마다 IndexedDB에 조각을 남긴다. 앱이 죽어도 마지막 5분만 잃는다. 다시 열면 복구 화면이 뜬다.

**업로드는 조각을 하나로 합쳐서 보낸다.** Stage 1이 "파일 하나 = 세션 하나"로 보기 때문에 조각을 따로 올리면 세션이 갈라진다.

## 아직 없는 것

- **업로드.** Google Drive OAuth가 필요하고 자격증명은 승인 대상이다. 지금은 파일을 내려받아 수동으로 올린다
- **푸시 알림.** 서버와 VAPID 키가 필요하다. 지금은 앱이 떠 있을 때만 로컬 알림이 뜬다
- **이어 녹음.** 복구 화면의 `이어서`는 지금 저장만 한다
- **Notion 회원 동기화.** 목록은 손으로 만든 JSON이다
- **인증.** 트레이너 계정 구분이 없다

## v1 사용 흐름

```
회원 고르기 → 날짜·시간·회차 확인 → [파일명 복사]
            → 음성 메모로 녹음 → 그 이름으로 저장
```

녹음은 음성 메모가 맡는다. 앱은 **이름을 틀리지 않게** 만드는 일만 한다. 그것이 오늘 실제로 비용을 낸 문제였다.
